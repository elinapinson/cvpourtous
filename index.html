Relisez votre document, puis imprimez-le ou enregistrez-le au format PDF.

Pour obtenir votre PDF : cliquez sur « Télécharger mon CV en PDF », puis sélectionnez « Enregistrer au format PDF » dans la fenêtre d'impression de votre navigateur. Vérifiez le format A4 et activez l'impression des arrière-plans/couleurs.

Données personnelles et cookies

Aucune donnée personnelle n'est collectée ni enregistrée, aucun cookie n'est utilisé.

Les informations saisies sont utilisées uniquement pour composer le CV affiché dans le navigateur. L'application ne dispose d'aucune base de données et n'envoie pas les informations à un serveur.

Contraintes techniques

  • Un seul fichier index.html, avec le HTML, le CSS et le JavaScript à l'intérieur ;
  • Aucune base de données ;
  • Aucune donnée enregistrée ;
  • Texte en français.

Responsabilité

L'utilisateur est responsable de la vérification des informations qu'il ajoute à son CV avant sa diffusion.
